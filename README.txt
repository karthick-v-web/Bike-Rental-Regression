# Bike-Sharing Rental Demand Prediction — Deployment

## Files
- `app.py`: Streamlit user interface for bike demand prediction.
- `requirements.txt`: Python packages required to run the app.
- `deployment_artifacts/`: Put the trained model files generated by the notebook here.

## Important: train and export the model first
Run `Bike_Sharing_Rental_Demand_Prediction_FIXED.ipynb` through the section
named **Save the trained model for deployment**. The notebook creates:
- `deployment_artifacts/bike_demand_model.joblib`
- `deployment_artifacts/model_metrics.json`
- `deployment_artifacts/feature_columns.json`

Copy that complete `deployment_artifacts` folder into this deployment folder,
beside `app.py`. The model file cannot be supplied yet because it is created
from your local training run.

## Run locally on Windows
Open Anaconda Prompt or Command Prompt and change directory to this folder:

```bash
cd path\to\Bike_Sharing_Deployment
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will display a local URL, usually `http://localhost:8501`.

## Notes
- Keep the saved model and scikit-learn version compatible with the environment
  used to train the model.
- This is a local prototype. Public hosting requires deploying the folder and
  model artifacts to a hosting service.
- Input weather values are normalised values on a 0–1 scale, consistent with
  the dataset's apparent feature representation. Check the dataset documentation
  before using real operational sensor values.
